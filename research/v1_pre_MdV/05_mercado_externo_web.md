### Diferencias entre el mapeo (research/00_mapeo_portillo.md) y la web
1. **Marcas.** El mapeo marca como hipótesis "PORT TOYOTA", "PORT HYUNDAI", "PORT PEUGEOT", "MG PLAZA EGAÑA PORTILLO", "PORT OPEL", "PORT CITROEN" etc. La lista pública de Portillo incluye todas esas marcas. Coincidencia fuerte, pero **la web no prueba qué sucursal pertenece a Portillo**: sigue pendiente confirmación de Beto / Iván Balaguera.
2. **Usados.** El mapeo trata "PORT USADOS ..." (Bilbao, La Dehesa, Cerrillos, etc.) como Portillo. La web público asocia el stock usado a **CLICAR**, y el mapeo asume que Clicar es hermana de grupo con 0 filas PORT. **Diferencia a validar:** en la web, el usado de Portillo se comunica bajo la marca Clicar. Esto puede cambiar qué universo cuenta como "Portillo".
3. **Prefijos GAP, ACSA, DENALI, COSE, SAIS.** La web no menciona estos códigos. Solo confirma que Salazar Israel, Coseche, Carflex/Cerflex y Servimaq son del grupo. **GAP, ACSA, DENALI: NO VERIFICADO** (no aparecen en fuentes públicas consultadas).
4. **Clicar.** El mapeo la trata como grupo hermano. La web lo confirma solo por fuente secundaria. Clicar en su propio sitio no declara vínculo con el grupo: **[WEB] no verificado en primaria**.
